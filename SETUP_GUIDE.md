# Setup Guide

See [SETUP.md](SETUP.md) for the deployment checklist and [README.md](README.md) for architecture, environment variables, health endpoints, and the profitability standard.

There is no risk-free live strategy: even a theoretically matched complete set can suffer one-sided fills, API ambiguity, cancellation failure, fees, or price movement. New accounts start paused. The current permitted scope is TAKER+MAKER on BTC/ETH/SOL at 5- and 15-minute timeframes; that scope is not a profitability claim, and legacy SNIPE performance data does not validate the current TAKER implementation. Keep live trading disabled until feeds, fills, and risk settings have been reviewed.
