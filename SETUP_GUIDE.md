# Setup Guide

See [SETUP.md](SETUP.md) for the deployment checklist and [README.md](README.md) for architecture, environment variables, health endpoints, and the profitability standard.

The old “full send” recommendations were removed because they exceeded the product's current safety policy. There is no risk-free live strategy: even a theoretically matched arbitrage can suffer one-sided fills, API ambiguity, cancellation failure, fees, or price movement. Single-leg post-only MAKER is available as an opt-in strategy; experimental multi-leg and oracle-latency strategies remain disabled by default.
